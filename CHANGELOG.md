## [1.0.0] — 2026-03-14

### Добавлено

- 📊 **Дашборд реального времени**
  - Карточки показателей: входное/выходное напряжение, частота, нагрузка (Вт), автономия, температура, батарея
  - Круговые датчики (GaugeWidget) — заряд батареи, нагрузка, температура
  - Анимированная блок-схема потока энергии (PowerFlowWidget)
  - Полосы параметров (BarMeter) с цветовой индикацией порогов
  - Индикаторы статусных флагов ИБП
  - График истории в реальном времени (pyqtgraph, опционально)

- ⚙️ **Вкладка Управление**
  - Тест батареи: 10 сек / до разряда / отмена
  - Управление выходом ИБП: выключить через N мин, выключить/включить, включить сейчас
  - Перезагрузка ИБП
  - Переключение пищалки (beeper)

- 🔧 **Вкладка Настройки**
  - Выбор COM-порта с автоопределением доступных портов
  - Кнопка 🔓 «Освободить порт» (PortKiller — многоступенчатое освобождение занятого порта)
  - Автоматическое завершение работы: по разряду батареи и/или при переключении на батарею
  - Настраиваемые пороги и задержки завершения работы
  - Автозапуск Windows (реестр HKCU\Run) с опцией «запускать свёрнутым»

- 📋 **Вкладка Журнал событий**
  - Хронологический лог всех событий ИБП
  - Фильтрация по уровню (INFO / WARNING / CRITICAL / ACTION)
  - Экспорт в CSV

- 📡 **Вкладка SNMP**
  - Поддержка RFC 1628 UPS MIB
  - Ручные запросы к SNMP-агенту ИБП

- 🔋 **Логика мониторинга**
  - Протокол Megatec Q1 (2400 бод, 8N1, RS232/USB)
  - Трёхуровневое автоопределение формата батарейного напряжения
  - Демо-режим при отсутствии подключения (симуляция данных)
  - Автоматический реконнект при потере связи

- 🛠️ **Сборка**
  - `build.bat` — автоматическая сборка EXE (PyInstaller, onefile, без консоли)
  - `ExeGate_UPS_Manager.spec` — конфигурация сборки
  - Поддержка `--minimized` для запуска в системный трей

- 🎨 **Интерфейс**
  - Тёмная тема (dark mode)
  - Системный трей с контекстным меню
  - Баннер обратного отсчёта при автоматическом завершении работы
  - Кнопка отмены завершения работы

### Исправлено

- Корректное определение кодировки вывода PowerShell/pnputil (cp866 / utf-8)
- Обработка ошибки `PermissionError(13)` на COM-порту — многоступенчатое освобождение через cfgmgr32 API, pnputil, реестр
- Отображение названий вкладок (setExpanding + ElideNone)
- Обрезание текста в GaugeWidget и BarMeter (динамическое позиционирование)
