## 📋 Описание

Полнофункциональный менеджер ИБП для Windows с тёмным интерфейсом.  
Аналог **APC PowerChute** и **Eaton UPSmon**, написанный на Python + PyQt5.

### Возможности

| Вкладка | Функции |
|---------|---------|
| 📊 **Дашборд** | Показатели в реальном времени, круговые датчики, анимированная блок-схема потока энергии, полосы параметров, графики истории |
| ⚙️ **Управление** | Тесты батареи (10 сек / до разряда), управление выходом ИБП, перезагрузка, пищалка |
| 🔧 **Настройки** | COM-порт, автозавершение работы при разряде, автозапуск Windows |
| 📋 **Журнал** | Все события с временными метками, экспорт в CSV |
| 📡 **SNMP** | Мониторинг по сети через RFC 1628 UPS MIB (требует SNMP-адаптер) |

### Анимированная блок-схема потока энергии

Отображает реальное состояние ИБП с движущимися точками потока:

```
[СЕТЬ ~AC] ──► [ВЫПРЯМИТЕЛЬ] ──► [DC-шина] ──► [ИНВЕРТОР] ──► [НАГРУЗКА]
                                       │
                                  [БАТАРЕЯ 96%]

         ╰──────────── BYPASS (байпас) ────────────╯
```

| Режим | Цвет |
|-------|------|
| 🟢 Сетевое питание | Зелёный → Голубой DC → Зелёный |
| 🟡 Питание от батареи | Жёлтый |
| 🟠 Байпас | Оранжевый |

## 🔌 Подключение ИБП

### USB (рекомендуется)

1. Подключить USB-кабель ИБП к ПК
2. Установить драйвер если нужно:
   - **CH340/CH341**: [скачать драйвер](https://www.wch-ic.com/downloads/CH341SER_EXE.html)
   - **CP2102** (Silicon Labs): [скачать драйвер](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers)
3. Проверить порт: **Диспетчер устройств → Порты (COM и LPT)**
4. В программе: **Настройки → COM-порт → Сохранить**

### RS232

Параметры: `2400 бод, 8N1, без управления потоком`  
Распиновка: RX(9) ↔ TX, TX(6) ↔ RX, GND(7) ↔ GND

## 🔧 Запуск из исходников (для разработчиков)

Если хотите запускать из `.py` файла, а не из EXE:

```bat
pip install -r requirements.txt
python ExeGate_PowerExpert_Manager.py
```

Сборка Windows x64: установите Python 3.14 и запустите `build.bat`.
Скрипт создаёт `.venv`, устанавливает фиксированные зависимости из
`requirements-build.txt`, выполняет тесты и собирает exe через PyInstaller.
SNMP включён в готовый exe и стандартные зависимости. Прямой USB HID не реализован;
USB-подключение работает через COM-драйвер.

Проверка исходников:

```bat
python -m unittest discover -s tests -v
```

Безопасная самопроверка сборки (не обращается к ИБП, не выключает ПК,
не читает и не меняет пользовательские настройки):

```bat
ExeGate_PowerExpert_Manager.exe --self-test smoke-result.json
```

Создаёт JSON с результатом и PNG окна. SNMP проверяется на локальном тестовом агенте.

## ⚙️ Протокол Megatec Q1

| Команда | Описание |
|---------|----------|
| `Q1\r` | Запрос состояния |
| `F\r` | Номинальные параметры |
| `I\r` | Информация об устройстве |
| `T\r` | Тест 10 секунд |
| `TL\r` | Тест до разряда |
| `CT\r` | Отмена теста |
| `S<n>\r` | Выключить выход через n минут |
| `C\r` | Отмена выключения |
| `Q\r` | Переключить пищалку |

## 📝 Совместимые модели ИБП

Целевое устройство — ExeGate TL-2000.72V. Другие модели с **Megatec / Q1** требуют проверки формата напряжения батареи и команд управления:

- ExeGate PowerExpert серии TL
- Ippon, PowerMan, APC Back-UPS (Q1-совместимые модели)
- Любые ИБП, поддерживаемые в [NUT (Network UPS Tools)](https://networkupstools.org/) как `megatec`

## ❓ Решение проблем

| Проблема | Решение |
|----------|---------|
| Порт не определяется | Переустановить драйвер USB-UART, проверить Диспетчер устройств |
| `PermissionError` на COM-порту | Нажать 🔓 «Освободить порт» → при необходимости запустить от имени Администратора |
| Нет ответа от ИБП | Проверить кабель, убедиться в правильном COM-порте (2400 бод) |
| Антивирус блокирует EXE | Сверьте SHA256 с файлом релиза; exe не подписан цифровой подписью |

## Изменения поведения в 1.1.0

- Температурное оповещение появляется при **достижении** установленного порога:
  при 50 °C значения 46 и 49,9 °C не вызывают его, 50 °C вызывает.
  Следующее оповещение возможно после охлаждения до 48 °C и повторного нагрева.
  Цвета температуры используют тот же порог.
- Галочки отдельных событий управляют всплывающим и звуковым оповещением.
  Сами события сохраняются в журнале окна; запись в CSV включается отдельно.
- Ручная отмена автозавершения действует до следующего подтверждённого восстановления
  сети. Потеря связи не означает восстановление: начатый отсчёт продолжается.
  Новые действия по недостоверным или демонстрационным данным не запускаются.
- При восстановлении сети отменяется как отсчёт программы, так и уже переданная
  ею ожидающая команда Windows. Неудачная отмена явно сообщается, состояние сохраняется.
- Параметр «Предупреждать за» работает; дублирующие уведомления удалены.
  Обычная команда выключения выполняется по завершении отсчёта программы без скрытой
  дополнительной минуты. Старый стандартный `/t 60` автоматически заменяется на `/t 0`;
  пользовательские команды сохраняются. После начала немедленного выключения отмена не гарантируется.
- Интервал опроса меняется без перезапуска; изменение соединения вызывает переподключение.
  Сброс настроек обновляет виджеты и сохраняет настоящие значения по умолчанию.
- SNMP: фоновый опрос SNMPv2c, ручные запросы не блокируют интерфейс. Для автоматики
  необходимы корректные UPS MIB поля состояния питания, батареи и заряда.
  Используются первая входная и выходная линии. Управление выходом ИБП через SNMP не реализовано.
- Паспортные данные I/F сохраняются между опросами. Автономия и заряд Q1 — оценки;
  реальное время работы зависит от батарей и нагрузки. При потере связи карточки
  сохраняют последние значения, а статус показывает отсутствие достоверных данных.

Протокол SNMP и единицы измерения: [RFC 1628](https://www.rfc-editor.org/rfc/rfc1628).
Беззвучные уведомления Windows используют [NIIF_NOSOUND](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ns-shellapi-notifyicondataw).
